## Checklist to building a Website / Web-App

> **What is all about your website(idea of that website) :**
>
> _**Example : landing page,ecommerce,webapp,blog website,streaming app,etc..**_

> **Information about that website :**
>
> _**Collect as many information/content for your website and make a document of that website.**_
>
> - What will my title will be.
> - What will be the text content of each page and post for my website.
> - What the media content i want like(images/logos/icons/maybe . video and audio files etc..).

> **How should your website look like(design) :**
>
> _**This is the crucial part of the the website is how you are going to present the content to the end user.**_ > **_for that:_**
>
> - Search for the website designs related to your website topic and type.
> - Make a rough layout of how each page should look like and each product or post will look like.
> - Use a design tool like figma/adobe xd if you want to take it a way ahead(this step is optional).
> - Choose a color theme and font for your website this changes the game of design for your website and make your website look cool!.

> **Choosing the technology to work with :**
>
> - Choosing what technology to work with is also a very crucial part in development.
> - You can choose depending on the project or the client requirements and your skillset.
> - For personal project you can choose to work with whatever technology you want.

     **For example:**

     - Work with pure html/css/js may with some css and js libraries.
     - Or choose a js framework like react.
     - For a backend choose what server-side language you want/you know to work with.

Planning this in each project before ahead will save you lots and lots of time while you building and testing the Website/Web-app

### Next step is setting up file systems and choosing the medium to deploying your Website/Web-App

#### File systems :

> **For simple front-end website using html/css/js**
>
> Here is the simple file system setup for your project.
>
> - `<root-directory>`(you can name this is anything this the main folder for your project) all other files and folder should be inside this root directory.
> - Inside `<root-directory>` there should be a folder named `index.html` file this is the main file displays once some one enters your website url.
> - You can create a directory named `styles` and put all the css files inside this styles directory.
> - And you can create a directory named `scripts` and put all the necessary js files inside it.
> - And for your image files create a directory named `src` or `images` as you wish and put the images on that folder and link to.
> - If you are going with multipage website without backend(generally it will not happen) you can create a folder named `pages` and put other html pages except `index.html` page.
> - All of your files and libraries should be linked with `index.html` file

> **If you are working with a web-app using a framework and for backend:**
>
> - You need to install and learn how to use a tool called package-manager that helps to install and manage the tools you want.
> - Depending on the language the package manager changes for Javascript NPM is prefered package managers and for Python Pip is the package manager.
>   links for both: (package manager comes default with the language package)
>   - https://nodejs.dev/
>   - https://www.python.org/
> - Using that you can install what ever libraries you want to use and and you can manage each and every libraries version and dependancies of that libraries in your project.
> - Also you can writes some scripts to initialise the project and setup file system and run the project in your local development server.
> - you will learn that when you start learning and using that particular framework or library.

#### Deploying your project :

> **You need two most important things to deploy your projects.**
>
> 1. Domain name for your website.(you need to buy the domain if your website is a serious professional website)
> 2. Hosting provider/cloud provider to deploy your coded Website/Web-app to a server platform

> - As you are learning programmer you don't have money for to buy domain name and rent a server from a cloud provider and to maintain it.
> - For that there are free alternatives for developers for showcasing projects
> - First learn use tools Git version control(you can track the codebase if any problem arives you can revert back its like a history for your code base) and,
> - Github to show your codebase on internet and other developers can collaborate on your projects
> - here are some free hosting providers to deploy your showcase projects
>   - Github pages(this is only for html/css/js websites) https://pages.github.com/
>   - Netlify (here you can host from simple website to complex Web-app whether only front-end or using back-end)
>     https://www.netlify.com/
>   - heroku (similar to netlify)
>     https://www.heroku.com/
>   - firebase (mainly used for mobile apps backend/database)
>     https://firebase.google.com/
>   - Aws (for large production level project and this needs some devops knowledge to setup the server)
>     https://aws.amazon.com/
